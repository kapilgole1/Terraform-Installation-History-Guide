# Terraform Installation and History Guide

This repository contains focused notes for learning Terraform, infrastructure as code, installation, and common Terraform workflows.

## Guides

1. [Definition and History of Terraform](A.%20Definition-History-of-Terraform.md)  
	Learn what Terraform is, how it works, and how it developed.

2. [Current Trends and News in Terraform Development](B.%20Current%20Trends%20%26%20News%20in%20Terraform%20Development.md)  
	Review current practices such as remote workflows, modules, policy checks, testing, and drift management.

3. [Infrastructure as Code: Why It Matters](C.%20Infrastructure%20as%20Code%20-%20Why%20it%20matters.md)  
	Understand the benefits, responsibilities, and limitations of managing infrastructure as code.

4. [Terraform Compared with Other Tools](D.%20Comparison%20with%20other%20Tools.md)  
	Compare Terraform with Ansible and AWS CloudFormation.

5. [Setup and Installation on a Local Machine and EC2 VM](E.%20Setup%20and%20installation%20on%20local%20machine%20%26%20EC2%20vm.md)  
	Install Terraform locally or on an AWS EC2 instance and run a basic test configuration.

## Suggested Reading Order

Start with the definition and history, learn why infrastructure as code matters, compare Terraform with related tools, review current practices, and then complete the installation guide.
